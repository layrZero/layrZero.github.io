# Fyers

Fyers is one of the four brokers enabled for Router-IMC production
registration.

## Setup

1. Activate Router-IMC in Layr0 Console and sign in at `https://imc.layr0.org`.
2. Open Broker Setup and select Fyers.
3. Copy the IMC callback URL and static IP shown for the broker configuration.
4. Enter the Fyers credentials requested by the form and complete the broker
   authentication flow.
5. Confirm the connected session, then generate the broker-specific IMC API
   key from API Keys.

Validate symbols and order payloads in Analyze mode before enabling live
execution. Broker capabilities and order types remain subject to the Fyers API.
