# Upstox

Upstox is one of the four brokers enabled for Router-IMC production
registration.

## Setup

1. Activate Router-IMC in Layr0 Console and sign in at `https://imc.layr0.org`.
2. Open Broker Setup and select Upstox.
3. Register the displayed callback URL and static IP in the Upstox developer
   application when requested.
4. Complete the Upstox OAuth/login flow in IMC and confirm the active session.
5. Generate the broker-specific IMC API key from API Keys.

Use Analyze mode for payload validation and Auto or Semi-Auto only after the
connected account and symbol format have been confirmed.
